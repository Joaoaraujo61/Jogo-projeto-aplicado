# Rota de Fuga

Jogo sobre a violência contra a mulher, desenvolvido durante a disciplina de **Projeto Aplicado II** da **Universidade do Distrito Federal (UnDF)**.

O objetivo do projeto é utilizar a linguagem de jogos como ferramenta de conscientização, abordando de forma interativa um tema social relevante.

## Tecnologias utilizadas

- **Java**
- **Swing** (interface gráfica)
- Projeto estruturado para **Eclipse** (`.classpath`, `.project`) e compatível com **IntelliJ IDEA** (`.idea`, `.iml`)

## Estrutura do projeto

```
├── src/            # Código-fonte do jogo
├── out/            # Arquivos compilados
├── .idea/          # Configurações do IntelliJ IDEA
├── .settings/      # Configurações do Eclipse
├── .classpath      # Configuração de build (Eclipse)
├── .project        # Configuração de projeto (Eclipse)
└── Jogo-projeto-aplicado.iml   # Configuração de módulo (IntelliJ)
```

## Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/Joaoaraujo61/Rota-de-Fuga.git
   ```
2. Abra o projeto na sua IDE de preferência:
   - **Eclipse**: `File > Open Projects from File System...` e selecione a pasta clonada.
   - **IntelliJ IDEA**: `Open` e selecione a pasta clonada (o projeto já contém as configurações `.idea`).
3. Compile e execute a classe principal do jogo a partir da pasta `src`.

## Sobre o tema

O jogo aborda a violência contra a mulher com o propósito de gerar reflexão e conscientização sobre o assunto, unindo desenvolvimento de software a uma causa social.
